# ドミノゲーム 市場調査レポート

調べた日: 2026年10月27日
目的: これから作る「ドミノが倒れる気持ちよさ」が中心のスマホ用ブラウザゲーム(3D・広告なし・課金なし・約100ステージ)の方向を決めるため
調べ方: ストアのページ、業界ニュース(PocketGamer.biz、Mobidictum など)、ゲーム制作の解説、研究論文。出典は各章の終わりにまとめた。

> 読み方のメモ
> - 「未確認」= ネットで裏付けがとれなかった数字や話。
> - 「(私見)」= 調べた事実ではなく、調査担当としての意見。
> - ダウンロード数などは調査会社の「推定」で、会社によって数字がちがう。

## 0. 先に結論(3行)

1. **ドミノの「倒れる気持ちよさ」は、今も人気がある。** ただし、2024〜2026年のランキング上位に「ドミノのゲーム」は見つからなかった。**席が空いている**とも言えるし、「ドミノというだけでは売れない」とも言える。
2. 私たちの案「走りながらドミノを並べ、うしろから倒れる波が追いかけてくる」は、**よその大ヒットの良いところを3つ合わせた形**で、筋が良い。ただし「**気持ちいい場面(倒れるところ)が、プレイヤーのうしろで起きて見えにくい**」という大きな弱点がある。カメラと演出で直すのが最重要。
3. 「追いつかれそうなギリギリほど点が高い」という**ギリギリ・ボーナス**を入れると、こわさが「わざと近づく楽しさ」に変わり、やみつきになりやすい。

### 1-2. ドミノを「見る」人気

- ドミノ作家 Lily Hevesh(ヘヴェシュ)さんの YouTube「Hevesh5」は、登録者約452万人・再生約23.5億回(Wikipedia)。1万5千個のドミノの「三重らせん」の動画は、2021年の時点で1億1,400万回以上見られている(CBS)。
- つまり、**「ドミノがザーッと倒れるのを見る」だけで気持ちいい**、という需要ははっきりある。
- (私見)ゲームの中でも、**「最後に自分がつくった列が全部倒れるのを、空からゆっくり見せる」場面**は、この動画と同じ気持ちよさを出せる。

### 1-3. わかったこと

- ドミノのゲームが大ヒットしたのは **2019年(Domino Smash と、そのまね)** がいちばん目立つ。その後、2024〜2026年に上位に入ったドミノのゲームは見つからなかった(ハイパーカジュアルの上位表、AppMagic の上位表に名前がない)。
- 人気の理由はどれも「**1回の操作で、ずらっと連鎖して倒れる**」こと。
- 不満は「**広告が多い**」「**同じことのくり返し**」「**むずかしさの上げ方が下手**(上がらない・急に無理)」の3つ。
- 「**走りながらドミノを置く**」「**倒れる波に追いかけられる**」という形の有名なゲームは、**見つからなかった**。私たちの案は、めずらしい組み合わせ。

## 3. やみつきにする仕組み

### 3-1. 業界の流れ(2024〜2026年)

- 「ハイパーカジュアル(1分で遊べる超かんたんゲーム)」だけでは、**すぐ飽きられる**ことが分かってきた。今は「**ハイブリッドカジュアル**」(かんたんな遊び + 長く続ける仕組み)が主流。
- 2025年4〜6月の上位10作は、Color Block Jam(Rollic)、Screwdom、All in Hole、Mob Control など。どれも「**かんたんな遊び + なめらかなむずかしさの上がり方**」が特ちょう(Mobidictum / AppMagic)。
- 長く続ける仕組みとして、**成長要素(集める・強くなる)、新しいステージ、新しいモード、連勝ボーナス、イベント**が使われている。
- 私たちは広告も課金もないので、「お金をとる仕組み」は不要。**「続ける理由」だけ**をまねすればよい。

### 3-2. 飽きられる理由(調査)

Facebook Gaming の調査(13,000人以上・11か国)では、ハイパーカジュアルをやめる理由は:
- アメリカ・イギリス: 「飽きた」「広告が多すぎ」「くり返しすぎ」が上位3つ
- 韓国: 「くり返しすぎ」42%、「飽きた」37%、「広告が多すぎ」27%
- 遊ぶ理由の1位は「**ストレス発散**」(アメリカ67%)。でも「ハイパーカジュアルで実際に発散できる」と答えたのはアメリカで46%だけ。

→ 広告なしは、それだけで大きな強み。残る敵は「**くり返し・飽き**」。だから **ステージごとに新しい仕掛け** を出すことが大事。

### 3-3. 「ギリギリ」の力

- ケンブリッジ大学の研究(Clark ほか、2009年)では、**「おしい!」(ニアミス)は、くやしいのに「もう1回やりたい」気持ちを強める**。しかも、**自分で操作しているとき**だけその効果が出た。2024年の追試でも「もう1回やりたくなる」点は同じ結果だった。
- 注意: この研究はスロット(ギャンブル)のもの。**おしい場面を「わざと作って、だます」のはよくない**(私見)。ゲームでは「**本当に自分の腕でギリギリだった**」ときに演出を強める、という使い方にする。

### 3-4. 仕組みごとの「ドミノに合うか」

| 仕組み | ドミノに合うか | 理由・使い方 |
|---|---|---|
| 星3つ評価 | ◎ | 星1=ゴール、星2=金のドミノを全部、星3=「ギリギリ」で走りきる、など。うまい人はやり直したくなる |
| ニアミス演出(ギリギリ) | ◎ | 波に追いつかれそうな時、**一瞬スローモーション + 心臓の音**。逃げきったら「ギリギリ!」の文字とボーナス |
| コンボ | ◎ | 途切れずに倒れ続けた数。音階が上がる(Stack 式) |
| スローモーション | ◎ | ゴールの大仕掛けが倒れる瞬間、巨大ドミノが倒れる瞬間に使う。**使いすぎない** |
| 集める要素 | ○ | 金のドミノ、ドミノの「着せかえ」(木・ガラス・お菓子・光る)、ワールドの最後の大仕掛けの「図かん」 |
| 着せかえ | ○ | 主人公・ドミノの見た目。課金なしなので**星の数で手に入る**ようにする |
| ステージごとの新しい仕掛け | ◎ | 飽き対策の本命。10面ごとに新しい仕掛け、と決めるとつくりやすい |

| 奇跡の助け | ○ | Domino Runnner の「MIRACLE」。**1面に1回だけ、途切れた所を自動でつなぐ**お助けなど |

## 4. まとめの提案

### 4-1. 中心の遊び方(コアループ)

**私たちの案の良い点**
1. **ほかにない。** 「走ってドミノを置く」「倒れる波に追われる」形の有名作は見つからなかった。
2. **スリルの理由が分かりやすい。** Temple Run の「追っ手」と同じ。説明なしで伝わる。
3. **追っ手が「自分の作ったドミノ」。** Paper.io の「自分の線が弱点」と同じで、ドミノならではの意味がある。
4. **ゴールの大仕掛けがごほうび。** Hevesh5 の動画のような「見る気持ちよさ」で終われる。
5. **操作がかんたん。** 左右に動かすだけなら、Survivor.io 級にだれでも遊べる。

**弱い点(気をつけること)**
1. **いちばん気持ちいい「倒れる場面」が、うしろで起きて見えない。** 前を見て走るので、ドミノが倒れるところを見るひまがない。→ 一番の課題。
2. **置くのが自動だと、プレイヤーの「選ぶこと」が少ない。** よけるだけのランナーになり、「ドミノのゲームである意味」がうすれる。
3. **途切れたら即負け、はきびしすぎる。** 初めての人がすぐやめてしまう。
4. **毎回同じ「走る→ゴール」だと飽きる。** 調査でも飽きの理由1位は「くり返し」。

**もっと良くする工夫(提案)**

| 工夫 | 内容 | 弱い点のどれを直すか |
|---|---|---|
| **カメラを「ななめうしろ・高め」に** | 主人公と、すぐうしろの倒れる波が**同じ画面に入る**ように。波が近づくとカメラが少し引く | 1 |
| **ゴール後の「空からのリプレイ」** | クリアしたら、自分の作った列がスタートから全部倒れていくのを、空から早送り → 最後の大仕掛けだけスロー。**ここがこのゲームの顔** | 1 |
| **ドミノの「残り本数」** | 置けるドミノには数に限りがある。道に落ちている束や「+20」「×2」の門で増やす。足りなくなると途切れる | 2 |
| **ギリギリ・ボーナス** | 波が近いほど点が増える(画面に「×3」など)。**わざと近づくか、安全に逃げるか**を選べる | 2 |
| **タップで「ジャンプ」(または「ダッシュ」)** | 画面の右側をタップ=ジャンプ。すき間を飛ぶと、**長い橋ドミノ**が1枚置かれる。左手=左右、右手=ジャンプ | 2 |
| **お助け「つなぎ直し」** | 1面に1回、途切れた所を自動でつなぐ(Domino Runnner の MIRACLE 式)。3回負けたら「とばす」も出す | 3 |
| **ワールドごとの新しい仕掛け** | 10面ごとに新しい仕掛け。下の 4-2 参照 | 4 |
| **ときどき「逆の面」** | 何面かに1回、**追いかける側**になる面(前を走る巨大な列に、自分の波で追いつく)や、**分かれて2列にする面**を入れる | 4 |

**1回の流れ(30〜60秒)**
1. スタート:ドミノを1枚倒すと、主人公が走り出す(置くのは自動)
2. 走る:左側で左右に動いて、ドミノの束や門を取る。じゃま物をよける。右側タップでジャンプ
3. うしろから波:だんだん速くなる。近いと音と赤いふちでハラハラ。近いほど点が増える
4. ゴール:最後の1枚が大仕掛けに当たる → スローモーションで大きく倒れる
5. 空からリプレイ → 星1〜3 → 「つぎへ」(負けたらすぐ「もう1回」)

### 4-2. ドミノならではの仕掛け(ギミック) 24個

「効くところ」: **ス**=スリル(ハラハラ)、**気**=気持ちよさ、**両**=両方

| # | 仕掛け | 一言の説明 | 効く |
|---|---|---|---|
| 1 | 分かれ道 | 道が2つに分かれる。近いけど危ない道と、遠いけど安全な道 | ス |
| 2 | スイッチで開く門 | ドミノの列でスイッチを倒すと、先の門が開く。波が届くまで門は閉まったまま | ス |
| 3 | 加速板 | 踏むと主人公が速くなる。でもドミノの間が広がって途切れやすい | ス |
| 4 | 巨大ドミノ | 途中に立っている大きなドミノ。波が当たると、ドーンと倒れて画面がゆれる | 気 |
| 5 | 色の門 | くぐるとドミノの色が変わる。同じ色の扉だけ通れる | ス |
| 6 | 坂(上り・下り) | 下り坂では波が速くなり、上り坂では遅くなる | ス |
| 7 | すき間と橋 | 道のすき間。ジャンプで「橋ドミノ」をかける | ス |
| 8 | 動くじゃま物 | 左右に動くかべ、転がる大玉、ふり子のハンマー | ス |
| 9 | 「+20」「×2」の門 | ドミノの残り本数を増やす。どっちを通るか一瞬で選ぶ | 両 |
| 10 | 爆弾ドミノ | 倒れると、まわりのドミノもまとめてはじき飛ばす派手な1枚 | 気 |
| 11 | 分かれるドミノ | 1列が2列、4列にふえる。画面いっぱいに倒れる | 気 |
| 12 | 楽器ドミノ | 倒れるとドレミの音が鳴る。うまく走ると曲になる | 気 |
| 13 | 階段 | ドミノが1段ずつ下っていく。リズムよく倒れる | 気 |
| 14 | 回る床 | 乗ると向きが変わる。列がうずまきになる | 両 |
| 15 | ジャンプ台 | 主人公が大きく飛ぶ。空中では置けないので、着地点に注意 | ス |
| 16 | 氷の道 | すべって左右がききにくい | ス |
| 17 | 強い風 | 横から風。ドミノが早めに倒れてしまうことがある | ス |
| 18 | トンネル(暗い) | 暗い中で、光るドミノだけが見える | 両 |
| 19 | ベルトコンベア | 床が動き、主人公が前や横に流される | ス |
| 20 | 水の上 | 浮かぶ板の上を走る。板がしずむ前に渡る | ス |
| 21 | 金のドミノ | 道に3つある。全部取ると星がもらえる(集める要素) | 気 |
| 22 | ピタゴラ装置 | 列の先がボール→シーソー→つり下がった物…と連鎖する(ルーブ・ゴールドバーグ式) | 気 |
| 23 | 2つの波 | 前と後ろ、または左右から波が来る(後半ワールド用) | ス |
| 24 | ゴールの大仕掛け | 巨大なビル、恐竜、ロケット、お城などが倒れる/飛ぶ。ワールドごとにちがう | 気 |

(私見)Human Dominoes のように、**ドミノの代わりに「人形」「本」「ペンギン」が倒れるおまけ面**を入れると、遊び心が出る。

### 4-3. 100ステージの組み立て方

**10面 × 10ワールド**。各ワールドに**新しい仕掛けを1つ**入れる。

**ワールドの中の10面の流れ(のこぎり形)**
| 面 | 中身 |
|---|---|
| 1 | 新しい仕掛けの**お試し**(負けにくい) |
| 2〜3 | その仕掛けに慣れる |
| 4〜6 | 前のワールドの仕掛けと**組み合わせ** |
| 7 | **ひと休み面**(短くて気持ちいいだけ。巨大ドミノや分かれる列) |
| 8〜9 | そのワールドで一番むずかしい |
| 10 | **大仕掛け面(ボス)**。長めのコースで、最後に巨大な物が倒れる |

→ 新しいワールドの1面目で、むずかしさを**一度下げる**。これを10回くり返しながら、全体は少しずつ上がる。

**ワールドの例**
| ワールド | 新しい仕掛け | 最後の大仕掛け(例) |
|---|---|---|
| 1 はじまりの公園 | なし(走る・置く・波だけ)、巨大ドミノ | 大きな積み木の塔 |
| 2 おもちゃの町 | 「+20」「×2」の門、金のドミノ | おもちゃの汽車 |
| 3 坂の村 | 坂、分かれ道 | 大きな風車 |
| 4 からくり工場 | スイッチの門、ベルトコンベア | ピタゴラ装置 |
| 5 空の島 | すき間と橋(ジャンプ)、ジャンプ台 | 気球 |
| 6 雪山 | 氷の道、風 | 巨大な雪だるま |
| 7 お祭り | 楽器ドミノ、爆弾ドミノ、色の門 | 打ち上げ花火 |
| 8 夜の遺跡 | トンネル(暗い)、動くじゃま物 | 巨大な石像 |
| 9 海 | 水の上、回る床 | 灯台 |
| 10 ドミノ城 | 2つの波、これまでの全部 | お城が全部倒れて、最後に「100」の文字が浮かぶ |

**むずかしさを上げる「つまみ」**(1つずつ上げる。いっぺんに上げない)
1. 波の速さ
2. コースの長さ(30秒 → 60秒)
3. じゃま物の数・動く速さ
4. ドミノの残り本数の少なさ
5. 仕掛けの組み合わせの数

**目安**: 星1(クリアだけ)なら、だれでも1〜3回で抜けられる面を多めに。むずかしさは「星3」で出す(うまい人向け)。

### 4-4. 見た目・演出・音で「気持ちいい」を出すポイント

**見た目**
- ドミノは**はっきりした色**(1列ごとにグラデーションで色が変わると、倒れる流れが目で追える)。
- 背景は**ひかえめ**にして、ドミノを目立たせる。
- 波の先頭に**ほこり・光の粒**を出して、「波がどこにいるか」を一目で分かるように。
- 古い iPhone でも動くように、**ドミノの数が多すぎない**よう、見えない遠くのドミノは消す(私見・技術面)。

**演出**
- **一瞬止める(ヒットストップ)**: 巨大ドミノが当たる瞬間に 0.05〜0.1秒だけ止める。長すぎると「固まった?」と思われる。
- **画面ゆれ**: 小さく・短く(0.1〜0.3秒)。大きいと酔う。
- **スローモーション**: ゴールの大仕掛け、ギリギリで逃げた瞬間だけ。
- **コンボの数字**: 倒れた数がポンポン増える。100、500 など区切りで大きく出す。
- **空からのリプレイ**: 1面が終わったら、自分の列が全部倒れるのを早送りで見せる(Hevesh5 の動画のように)。
- 演出を盛りすぎると、何が起きているか分かりにくくなる、という指摘もある。**大事な場面だけ強く**。

**音**
- **「カタカタカタ…」の音が気持ちよさの本体。** 波が速いほどテンポが上がる。
- **コンボが続くほど音階が上がる**(Stack 式)。
- **波が近いと「ドクンドクン」(心臓の音)** と低い音が大きくなる。Temple Run も追っ手の近さを音で伝えている。
- 大仕掛けが倒れたら、大きな「ドーン」+ 歓声。
- **注意(スマホのブラウザ)**: iPhone の Safari や LINE の中では、**画面をタップする前は音が出ない**決まりがある。最初の「スタート」タップで音の準備をする。LINE の中で本当に鳴るかは、**実機で確かめる必要あり**(LINE 専用の資料は見つからなかった)。
- **ぶるっとふるえる(バイブ)**: Android の Chrome では使えるが、iPhone の Safari では使えない(私見・技術の知識。要確認)。iPhone は音と画面ゆれで補う。

### 4-5. やってはいけないこと(はやりのゲームの不満から)

| やってはいけないこと | どこから分かったか | 私たちの対策 |
|---|---|---|
| 同じことのくり返し | やめる理由の1位(調査)、Domino Smash の声 | 10面ごとに新しい仕掛け、ひと休み面、逆の面 |
| むずかしさが上がらない | Domino Smash「むずかしさが上がらない」 | のこぎり形で全体は少しずつ上げる |
| 急に「ほぼ無理」な面 | Domino Smash「飛ばすボタンがほしい」 | 3回負けたら「とばす」「お助け」 |
| 負けた理由が分からない | (私見)ランナーでよくある不満 | 負けた瞬間に、**途切れた場所をスローで見せる** |
| やり直しが遅い | Helix Jump の強みの逆 | 1タップ・1秒以内でやり直し |
| 宣伝と中身がちがう | 「偽の広告」への強い不満 | 紹介画像・説明は、実際の画面そのままで |
| 演出の盛りすぎ・ゆれすぎ | ゲームの手ざわりの解説 | ゆれは小さく、スローは大事な場面だけ |
| 古い iPhone で重い・真っ白 | (私見・技術面) | ドミノの数をおさえる。3D が動かないときの代わりを出す |
| 長い説明・長い読み込み | Poki は「ダウンロード・登録・ポップアップなし、すぐ遊べる」を売りにしている | 開いて数秒で走れる。説明は1面目の中で見せる |
| ボス面を続けすぎる | レベルデザインの解説 | ボスは10面に1回だけ |
