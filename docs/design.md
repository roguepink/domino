# ドミノ ラッシュ — ゲームの設計(まとめ役)

市場調査(docs/research.md)の結論を取り入れた形。

## 1. ひとことで
**走ると、うしろにドミノが並ぶ。自分で並べたドミノの「倒れる波」が、うしろから追ってくる。**
にげきってゴールまで並べると、最後に大ドミノ(ワールドごとの大仕掛け)が倒れる。

- 参考: Temple Run(追っ手)+ Paper.io(自分の作った線が弱点)+ Count Masters(+20 ×2 の門)+ Stack(音階が上がる)
- ドミノのゲームは 2019 年の Domino Smash 以来 ヒットがない(席が空いている)。「走って並べて 追われる」形は ほかにない

## 2. 操作(これだけ)
- **左がわ(画面の左 6割)を さわったまま 左右になぞる** = 左右に動く(はなすと まっすぐ)
- **右がわを タップ** = ジャンプ(トゲ・転がる玉・穴をこえる)
- 前へは 自動で走る。ドミノも 自動で並ぶ(0.5m に1枚)
- パソコン: ← → / A D、スペース

## 3. 決まり
| こと | 決まり |
|---|---|
| ドミノの数 | はじめ 80 本くらい。1枚ごとに 1 本へる。箱(+20)・大きい箱(+50)・「+20」「×2」の門で ふえる。「-10」の門(ワナ)もある |
| 倒れる波 | 走り出して 約1.2秒で 最初の1枚が押される。だんだん速くなる(はじめ 4.4m/秒 → 最大 7m/秒)。主人公は 5.2m/秒 |
| つかまる | 波が いちばん新しいドミノまで来て、主人公が すぐそばにいた → 負け |
| 切れる | ドミノがなくなって 列が とぎれた → 波は止まる → 負け |
| 落ちる | 穴・しずんだ床に落ちた → 負け |
| 穴とジャンプ | 1マスの穴は 波が そのまま渡れる。2マス以上の穴は ジャンプでこえると、手前のドミノが「橋ドミノ」(背が高い)になって 波が渡れる(ドミノを 穴の長さ分 使う) |
| ゴール | ゴールの線をこえると、主人公は まん中へ寄って 大ドミノの前まで並べて よける。波が大ドミノを倒す → クリア |
| ★ | ★1 = クリア / ★2 = 金のドミノ 3つ 全部 / ★3 = 「ギリギリ」を 3回(波が 1.6m より近くまで来て、にげきる) |
| 点 | 倒れた数、ギリギリの時間、金のドミノ、箱、ゴール、残りのドミノ |
| お助け | 負けたとき 1面に1回「お助け」: 波が 2.5秒止まる / 落ちたら 近くの床に もどる / 切れたら +15本でつなぎ直し |
| とばす | 同じ面で 3回負けたら「この面をとばす」 |

### かくれた コツ(遊ぶ人が 自分で気づくと うれしい)
- **ジグザグに走ると、列が長くなるので 波が おくれる**(でもドミノを多く使う)。まっすぐ走ると ドミノの節約。
  → 「ドミノの数」と「波からの安全」の 取り引き。ここがゲームの奥の深さ
- 箱や金のドミノは、あぶない所(穴のふち・のこぎりの近く)に置いてある

## 4. 10 のワールド(10面ずつ)
各ワールドで 新しい仕掛けを1つ入れる(js/worlds.js)。

| W | 名前 | 新しい仕掛け | ゴールの大仕掛け |
|---|---|---|---|
| 1 | はじまりの公園 | 走る・並べる・にげる / 箱 / 金のドミノ / かべ / 巨大ドミノ(D) | 積み木の塔 |
| 2 | おもちゃの町 | 「+20」「×2」「-10」の門 / ダッシュ板(^)/ ぬかるみ(~) | おもちゃの汽車 |
| 3 | からくり工場 | スイッチ(k)と門(K)/ ベルトコンベア(< >) | からくり装置 |
| 4 | 空の島 | 穴とジャンプ(橋ドミノ)/ ジャンプ台(J) | 気球 |
| 5 | あぶない森 | のこぎり・転がる玉・ハンマー / トゲ(x) | 大きな木 |
| 6 | 雪山 | 氷(i)/ 強い風 | 雪だるま |
| 7 | お祭り | 爆弾(o)と こわれるかべ(W)/ 音のドミノ(n)/ 2列の門 | 打ち上げ花火 |
| 8 | 海 | しずむ床(f)/ うず(ベルト) | 灯台 |
| 9 | 夜の遺跡 | 暗やみ / 前から倒れてくる列(rival) | 石像 |
| 10 | ドミノ城 | これまでの全部 | お城 |

### ワールドの中の 10 面(のこぎり形)
| 面 | 中身 |
|---|---|
| 1 | 新しい仕掛けの お試し(負けにくい・短い) |
| 2〜3 | 慣れる |
| 4〜6 | 前のワールドの仕掛けと 組み合わせ |
| 7 | ひと休み(短くて気持ちいい。巨大ドミノ・2列の門・金のドミノたくさん) |
| 8〜9 | そのワールドでいちばん むずかしい |
| 10 | 大仕掛け面(長め 60秒くらい。最後に 大仕掛け) |

新しいワールドの1面目で、むずかしさを 一度下げる。全体は少しずつ上げる。

### むずかしさの「つまみ」(1つずつ上げる)
1. 波の速さ(wave.v0 / acc / max / delay)
2. コースの長さ(30m 〜 200m。主人公は 5.2m/秒 = 100m で 約20秒)
3. じゃま物の数・速さ
4. ドミノの少なさ(stock)
5. 仕掛けの組み合わせの数

**目安**: ★1(クリアだけ)なら だれでも 1〜3回で ぬけられる。むずかしさは ★2・★3 で出す。

## 5. 見た目・演出(3D見た目・演出係)
- カメラは「ななめうしろ・高め」。**主人公と、すぐうしろの倒れる波が 同じ画面に入る**。波が近いと 少し引く
- ドミノは はっきりした色。列にそって 色が少しずつ変わる(虹色のグラデーション)。白い点(目)のもよう
- 波の先頭に ほこり・光の粒。倒れる音と見た目が そろう
- 主人公は 白いドミノに 顔と足がついた「ドミくん」(にげる顔がかわいい・こわがる)
- クリア → 大ドミノがスローで倒れる → 「空からのリプレイ」(列が全部倒れるのを 早送りで見せる)→ 結果
- 負け → その瞬間を スローで見せる(つかまった・切れた場所・落ちた所)
- ゆれは小さく・短く。スローは 大事な場面だけ

## 6. 音(音係)
- **カタカタの音が 気持ちよさの本体。** 波が速いほど テンポが上がる。コンボで 音階が上がる
- 波が近いと 心臓の音(ドクンドクン)
- 大ドミノ: 大きな「ドーン」+ 歓声。ワールドごとの BGM(短い くり返し)

## 7. 画面(UI・UX係)
- タイトル → ワールドの地図(ステージ選び)→ ステージの前(名前・★の条件・タップでスタート)→ プレイ → 結果
- プレイ中の上: 進み具合のバー(スタート ― 波 ― 主人公 ― ゴール)、ドミノの残り、★、点、ポーズ
- 波が近いと 画面のふちが赤く、「ギリギリ!」の文字
- 1面目は 指の絵で 操作を見せる(説明の文は 最小)
- 着せかえ: ★の数で ドミノの色・もよう・主人公の見た目が手に入る
